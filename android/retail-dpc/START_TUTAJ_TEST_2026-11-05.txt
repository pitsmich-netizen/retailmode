RETAIL DPC 0.8.2 — TEST ZACHOWANIA APLIKACJI SYSTEMOWYCH

To jest dzialajaca baza DPC 0.8.2 z flaga
DevicePolicyManager.EXTRA_PROVISIONING_LEAVE_ALL_SYSTEM_APPS_ENABLED = true
zwracana z ACTION_GET_PROVISIONING_MODE. Wersja app/build.gradle: 11 / 0.8.2.

1. Uruchom PRZYGOTUJ_GRADLE.bat (pobiera i weryfikuje gradle-wrapper.jar).
2. Android Studio -> Open -> ten folder -> Gradle JDK 17 lub 21.
3. Build -> Generate App Bundles or APKs -> Generate APKs.
4. APK: app\build\outputs\apk\debug\app-debug.apk
5. PowerShell: Get-FileHash "PELNA_SCIEZKA_DO_APK" -Algorithm SHA256
6. Opublikuj to APK w GitHub Release pod publicznym linkiem HTTPS.
7. W generatorze QR 1.1.1 ustaw URL APK i jego aktualny SHA-256.

WAZNE: DPC instaluje Retail Mode z URL zapisanego w
app/src/main/java/com/example/retaildpc/Constants.java.
Domyslnie jest to release rmtest ze STAREGO repozytorium retailmode.
Upewnij sie, ze stary URL RetailMode.apk tez jest publicznie dostepny.
Jesli zmienisz adres RetailMode.apk, trzeba podmienic Constants i skompilowac DPC ponownie.

Nie resetuj telefonu z dzialajacym demo, zanim sprawdzisz publiczne APK i hash.
